> 此文件由 `code2note` / `img2note` 命令自动生成，或通过 `/update-note-rules` 手动刷新。

## 文档类与核心宏包

- **文档类**: `\documentclass[10pt,b5paper,openany,twoside]{ctexbook}`
- **核心**: `rainbow`（定理类环境着色）、`bookstyle`
- **索引**: `imakeidx`，`\makeindex[title=关键词索引, columns=2, columnsep=1.5cm, intoc, options=-s pinyin.ist]`
- **符号说明**: `\input{符号说明.tex}`（在正文开头）
- **行距**: `\setstretch{1.3}`
- **公式间距**: `\abovedisplayskip=4pt` / `\belowdisplayskip=4pt` / `\abovedisplayshortskip=0pt` / `\belowdisplayshortskip=3pt`
- **全局 displaystyle**: `\everymath{\displaystyle}` — 行内公式自动使用行间样式

## 定理类环境

| 环境            | 含义 | 标题用法                                | 索引要求               |
| --------------- | ---- | --------------------------------------- | ---------------------- |
| `definition`  | 定义 | `\begin{definition}[标题]\index{...}` | 必须有 `\index{...}` |
| `theorem`     | 定理 | `\begin{theorem}[][label]`            | 建议加                 |
| `proposition` | 命题 | `\begin{proposition}[]`               | 不强制                 |
| `lemma`       | 引理 | `\begin{lemma}[]`                     | 不强制                 |
| `corollary`   | 推论 | `\begin{corollary}[标题]`             | 建议加                 |
| `proof`       | 证明 | `\begin{proof}...\end{proof}`         | 无                     |
| `instance`    | 例子 | `\begin{instance}...\end{instance}`   | 无                     |
| `property`    | 性质 | `\begin{property}[]`                  | 无                     |

## 注释/提示类环境

| 环境          | 含义 | 标题用法                          | 编号       | 说明                              |
| ------------- | ---- | --------------------------------- | ---------- | --------------------------------- |
| `remark`    | 注   | `\begin{remark}[标题]`          | 按章节编号 | 灰色，`\colorbf` 可用           |
| `note`      | 注解 | `\begin{note}[key=val...]`      | 无编号     | 青色左边框 tcolorbox，图标 `□` |
| `important` | 重要 | `\begin{important}[key=val...]` | 无编号     | 紫色左边框，图标 `!`            |
| `warning`   | 警告 | `\begin{warning}[key=val...]`   | 无编号     | 金色左边框，图标 `△`           |
| `example`   | 例题 | `\begin{example}[标题]`         | 按章节编号 | 绿色，按 `\colorbf` 可用        |

> `remark`、`example` 为普通段落环境（继承 `\colorbf` 颜色）。
> `note`、`important`、`warning` 为 tcolorbox 环境，支持 `breakable`（可跨页），可通过可选参数 `[colback=..., left=..., ...]` 调整样式。
> `note` 环境内部 `\colorbf` 颜色自动设为青色 (`rbNoteColor`)；`important` 和 `warning` 类似。

## 索引格式

- 所有 `definition` 环境后必须跟 `\index{...}`
- 命名格式: `\index{拼音首字母@中文!子类拼音首字母@子类中文}`
- 简单条目: `\index{拼音@中文}`
- 示例: `\index{d@代数!y@域上的代数}`, `\index{m@模!a@A-模}`, `\index{p@Peirce 分解}`

## 自定义命令速查

### 数学运算符（已由 `\DeclareMathOperator` 声明）

- `\End` → End
- `\Hom` → Hom
- `\im` → Im
- `\ker` → Ker（直接用 `\ker`，未额外声明）
- `\coker` → coker
- `\coim` → coim
- `\st` → s.t.

### 黑体/花体简写

- `\mb{R}` → `\mathbb{R}`
- `\mbb{R}` → `\mathbb{R}`（别名）
- `\mcal{H}` → `\mathcal{H}`

### 希腊字母简写

- `\a`=`\alpha`, `\b`=`\beta`, `\d`=`\delta`, `\D`=`\Delta`
- `\l`=`\lambda`, `\lam`=`\lambda`, `\m`=`\mu`
- `\p`=`\uppi`, `\th`=`\theta`
- `\leq`=`\leqslant`, `\geq`=`\geqslant`

### 格式与间距

- `\colorbf{...}` — 在定理类环境和提示类环境中高亮被定义的术语
- `\bluebf{...`} — 正文内高亮关键词
- `\setjot[#1]` — 调整公式行距
- `\par` — 段落结束（用于环境和定义内的分段）
- `\ab(...),\ab[...],\ab\{...\}` — 自适应大小括号(相当于 `\right(...\left)`等命令)（由 physics2 ab.legacy 提供）
- `\exactseq{...}` — 正合列（由 exactseq 宏包提供）
- `\cref{label}` — 智能引用（cleveref）

### 特殊符号

- `\bm{1}` — 恒等映射的粗体 1
- `-\!\!` — 紧排负号（用于 $F-\!\!$代数）
- `\st` — "使得"
- `\leq,\geq` 小于等于号，大于等于号

## 段落与换行

- 不同定义/定理之间用空行分隔
- 环境内多段文本用 `\par` 分隔
- 无 `\par` 时，一个自然段在环境内自动结束

## 公式

- **行间公式**: `\begin{equation*}...\end{equation*}`（不用 `$$ ... $$`）
- **编号公式**: `\begin{equation}...\end{equation}`
- **多行对齐**: `\begin{align*}...\end{align*}`（无编号）
- **行内简短公式**: `$...$`
- 矩阵用 `\begin{pmatrix}...\end{pmatrix}`，省略号用 `\cdots`（水平）、`\vdots`（垂直）、`\ddots`（对角）

## 图片

- **交换图/几何图**: `\begin{tikzcd}...\end{tikzcd}`（TikZ cd 库）
- **多图排列**: `\begin{figure}[H]\centering\begin{subfigure}[b]{宽度}...\end{subfigure}...\end{figure}`
- **占位图片**: `\includegraphics{example-image}` + `% TODO: 替换为实际图片`
- **图片路径**: 使用 `\graphicspath{{./images/}}`（如有）
- **标题**: `\caption{...}`

## 禁止的命令

- 不使用 `\begin{definition}` 的等价格式（如 `\begin{defn}`）
- 不使用自定义数学命令替代标准命令: 用 `\mathbb{R}` 而非 `\R`，用 `\mathcal{H}` 而非 `\cH`
- 不使用 `$$...$$` 行间公式

## 章节结构

- 最高级: `\chapter{...}`
- 次级: `\section{...}`
- 输入: `\input{文件名.tex}`
