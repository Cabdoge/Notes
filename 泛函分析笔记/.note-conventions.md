# LaTeX 写作规范（自动生成，勿手动编辑）

> 由 code2note / img2note 自动生成，或通过 /update-note-rules 手动刷新。

## 文档类与核心宏包

- 文档类：`ctexbook`，选项 `10pt,b5paper,openany,twoside`
- 核心宏包：`rainbow`（定理类环境）、`bookstyle`（章/节/页眉/目录样式）
- 索引：`imakeidx`，选项 `title=关键词索引, columns=2, columnsep=1.5cm, intoc, options=-s pinyin.ist`
- 数学：`amsmath`, `amssymb`, `stmaryrd`, `bm`, `physics2`（模块 `ab.legacy,op.legacy,qtext.legacy`）
- 图形：`tikz`（库 `decorations.pathreplacing,arrows.meta,cd`）, `graphicx`, `float`
- 表格：`makecell`, `longtable`, `multicol`, `multirow`
- 其他：`cleveref`, `enumitem`, `setspace`（`\setstretch{1.3}`）, `\everymath{\displaystyle}`

## 索引格式

- 命名规则：`\index{拼音首字母大写@中文名 环境类型}`
- 示例：`\index{n@内积}`、`\index{R@Riesz 表示定理}`、`\index{t@凸包}`
- 使用 `pinyin.ist` 排序样式

## 自定义命令速查

- 黑体/花体简写：`\mb{...}` → `\mathbb{...}`, `\mcal{...}` → `\mathcal{...}`
- 括号与范数：`\ab{...}` → 自适应括号, `\norm{...}` → `\|...\|`, `\aab{...,...}` → `\langle...,...\rangle`
- 文本运算符：`\st` → `\,\text{s.t.}`, `\aew` → `\,\text{a.e.}`, `\ie` → `\,\text{i.e.}`
- 微分与常数：`\d` → `\mathop{}\!\mathrm{d}`, `\eu` → `\mathrm{e}`, `\iu` → `\mathrm{i}`
- 收敛箭头：`\weakstar` → `\stackrel{*}{\rightharpoonup}`
- 声明的运算符：`\spann` (span), `\dist` (dist), `\ran` (ran), `\Spec`, `\Aut`
- 其他运算符使用 `\operatorname{...}` 内联声明（如 `\operatorname{conv}`, `\operatorname{Ext}`）
- 格式命令：`\colorbf{...}` (环境对应色加粗), `\bluebf{...}` (结构色加粗), `\par` (段间距)
- 智能引用文本：`\qin` (在…中), `\qif` (如果)
- 箭头：`\xlongequal`, `\xrightarrow`

## 段落与换行

- 环境内多段使用 `\par` 分隔（不空行）
- 环境外正文段落用空行分隔
- 无段落缩进覆盖

## 公式

- 重要公式/定义式用 `equation*` 或 `equation`(如果要编号)
- 多行推导用 `align*` 或 `aligned`
- `\everymath{\displaystyle}` 已启用，行内公式自动 displaystyle
- 公式间距已全局压缩（`\abovedisplayskip=4pt` 等）

## 章节结构

- `\chapter{...}` → `\section{...}` 层级
- 各章节独立 `.tex` 文件，通过 `\input{...}` 引入主文件
- 有 `符号说明.tex`（`\chapter*`，longtable 格式）
- 有 `cover.tex`（封面）

## 禁止的命令

- 不使用 `\begin{proof}[...]\end{proof}` 外的其他 amsthm 环境
- 不使用裸 `\langle\rangle` 于定理陈述中（用 `\aab` 替代，但证明中可用裸写法）
- 不覆盖项目自定义的 `\leq`/`\geq`（已重定义为 `\leqslant`/`\geqslant`）
