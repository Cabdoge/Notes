\chapter{平面圆锥曲线}

本章首先研究圆锥曲线的几何性质，以此作为引入射影平面 \(\mathbb{P}^2\) 这一课题的动机.射影几何通常在本科二年级的几何课程中有所涉及，此处将回顾其部分显著特征，重点关注齐次坐标，而暂时忽略线性子空间的几何以及“交比”等概念.对读者而言，最重要的目标是理解几何思想（例如，“无穷远点”对应于曲线的渐近方向）如何通过坐标来精确表达.直观的几何图像（它告诉我们应期待什么）与坐标的精确定义（它使我们能驾驭直觉）之间的互动，正是代数几何的魅力所在.

\section{参数化曲线示例}

勾股定理指出，在下图所示的直角三角形中，边长满足方程：

\begin{center}
\includegraphics[max width=0.2\textwidth]{images/bo_d3lj80c601uc738kffi0_16_718_1301_238_171_0.jpg}
\end{center}
\[
X^2 + Y^2 = Z^2
\]
\par
众所周知，\((3,4,5)\) 和 \((5,12,13)\) 都是勾股数.问题在于如何找出所有的整数解？该方程是齐次的，若令 \(x = X/Z, y = Y/Z\)，则它对应于单位圆 \(C : x^2 + y^2 = 1 \subset \mathbb{R}^2\).这个圆可以被参数化为

\[
x = \frac{2\lambda }{{\lambda }^{2} + 1},\;y = \frac{{\lambda }^{2} - 1}{{\lambda }^{2} + 1},\;\text{其中}\;\lambda  = \frac{x}{1 - y};
\]

由此可得通解:

\(
X = 2\ell m, \quad Y = \ell^2 - m^2, \quad Z = \ell^2 + m^2
\)
其中 \(\ell, m \in \mathbb{Z}\) 互素（若 \(\ell, m\) 均为奇数，则各项需再除以 2）.注意，由于方程是齐次的，若 \((X, Y, Z)\) 是一个解，则 \((\lambda X, \lambda Y, \lambda Z)\) 对任意 \(\lambda\) 也是解.

这种参数化方法在中学几何中或许已经为人所知，并且其正确性也容易验证.然而，即便事先不知，我们也可以通过一个简单的几何构造——即从圆上一点出发的线性射影——来推导出它.\par
取定点 \(P = (0,1) \in C\)，对任意有理数 \(\lambda \in \mathbb{Q}\)，过 \(P\) 且斜率为 \(-\lambda\) 的直线 \(L_{\lambda}\) 与圆 \(C\) 交于另一点 \(Q_{\lambda}\).这种基于线性射影构造映射的方法将在后续学习中反复出现.

\section{类似的例子}

考虑圆锥曲线 \(C : 2X^2 + Y^2 = 5Z^2\).使用同样的方法，可以导出如下的参数化 \(\mathbb{R} \to C\)：

\[
x = \frac{2\sqrt{5}\lambda }{1 + 2{\lambda }^{2}},\;y = \frac{2{\lambda }^{2} - 1}{1 + 2{\lambda }^{2}}.
\]

这使我们能够理解所有系数属于 \(\mathbb{R}\) 的 \(C\) 上的点，且与前一个例子没有实质区别；那么如果将\(\mathbb{R}\)改为\(\mathbb{Q}\)，情况会如何变化呢？
\begin{proposition*}
如果 \(\left( {a,b,c}\right)  \in  \mathbb{Q}\) 满足 \(2{a}^{2} + {b}^{2} = 5{c}^{2}\) ，则 \(\left( {a,b,c}\right)  = \left( {0,0,0}\right)\).
\end{proposition*}
\begin{proof}
通过乘以公分母并提取公因子，可以假定 \(a, b, c\) 是不全被$5$整除的整数.如若不然，\(5 \mid a\) 且 \(5 \mid b\)，则 \(2a^2+b^2\) 是 25 的倍数，从而 \(25 \mid 5c^2\)，即 \(5 \mid c\)，那么它们就有公因子$5$，可以被提取出来.\par
因此 \(2a^2 + b^2 \pmod 5\) 的取值必为 \(0+1,0+4,2+0,2+1,2+4,8+0,8+1\)或$8+4\mod 1$之一，
然而，它们均不能表现为$5c^2$的形式.
\end{proof}

注意，这是一个纯算术的论证.

\section{\(\mathbb{R}^2\) 中的圆锥曲线}

\(\mathbb{R}^2\) 中的圆锥曲线是由二次方程定义的平面曲线：
\[
q(x,y) = ax^2 + bxy + cy^2 + dx + ey + f = 0
\]

非退化圆锥曲线的分类广为人知：

\begin{center}
\includegraphics[max width=0.7\textwidth]{images/bo_d3lj80c601uc738kffi0_18_341_562_1004_212_0.jpg}
\captionof{figure}{非退化圆锥曲线：(a) 椭圆；(b) 抛物线；(c) 双曲线}
\end{center}
\hspace*{3em} 


此外，还有一些特殊情况:

\begin{enumerate}[(a)]
    \setcounter{enumi}{3}
    \item 单点：由 \(x^2 + y^2 = 0\)给出$(0,0)$；
    \item 由 \(x^2 + y^2 = -1\)、\(x^2 = -1\) 或 \(0 = 1\) 等方程给出的空集.尽管这些方程在 \(\mathbb{R}^2\) 中定义了相同的点集（空集），但它们的复数解集是不同的.
    \item 直线：\(x = 0\)；
    \item 直线对：\(xy = 0\)；
    \item 平行直线： \(x(x - 1) = 0\)；
    \item 二重直线：\(x^2 = 0\)；你可以自行决定是否允许最后一种情况：
    \item 全平面：\(0 = 0\).
\end{enumerate}

\section{射影平面}

射影平面 \(\mathbb{P}^2\) 可以“凭空”地定义如下：
\begin{align*}
\mathbb{P}^2(\mathbb{R}) &= \{\mathbb{R}^3 \text{中所有经过原点的直线}\} \\
&= \{ \text{点的比例 } X:Y:Z \} \\
&= (\mathbb{R}^3 \setminus \{0\}) / \sim, \quad \text{其中 } (X,Y,Z) \sim (\lambda X, \lambda Y, \lambda Z), \forall \lambda \in \mathbb{R} \setminus \{0\}
\end{align*}

（有经验的读者可以轻松地将 \(\mathbb{R}^3\) 推广到任意域上的向量空间，并用更内在的论证替代坐标计算.）

为了表示比例 \(X:Y:Z\)，当 \(Z \neq 0\) 时，可以令 \(x = X/Z, y = Y/Z\).这使得一个比例关系对应于唯一的实数对 \((x,y)\).换言之，\((X,Y,Z)\) 在关系 \(\sim\) 下的等价类有唯一的代表元 \((x,y,1)\)，其第三个坐标为 1.然而，当 \(Z=0\) 时，这种选取代表元的方法便不再适用.这表明 \(\mathbb{P}^2(\mathbb{R})\) 包含了一个 \(\mathbb{R}^2\) 的副本，即仿射部分.如图所示：

\begin{center}
\includegraphics[max width=0.4\textwidth]{images/bo_d3lj80c601uc738kffi0_19_646_280_616_328_0.jpg}
\captionof{figure}{通过映射 \((x,y) \mapsto (x,y,1)\) 将 \(\mathbb{R}^2\) 嵌入到 \(\mathbb{P}^2(\mathbb{R})\) 中}
\end{center}
\hspace*{3em} 

一般来说，\(\mathbb{R}^3\) 中过原点的一条直线不包含在平面 \(Z=0\) 内，则它与平面 \(Z=1\) 恰好相交于一点，该点即为此等价类的代表元.而平面 \((Z=0)\) 内的直线永不与平面 \((Z=1)\) 相交，它们对应的不是 \(\mathbb{R}^2\) 中的点，而是“无穷远方向”，或是对应于\(\mathbb{R}^2\)中的平行线束.因此，可以将 \(\mathbb{P}^2(\mathbb{R})\) 视为由 \(\mathbb{R}^2\) 以及每个平行线族的“无穷远点”所组成.从这个角度看，我们可以在 \(\mathbb{R}^2\) 中进行计算，并通过某种“渐近”论证来推测无穷远处的情况，然后在必要时使用齐次坐标进行严格证明.以 \(\mathbb{R}^3\) 中的直线作为定义，使 \(\mathbb{P}^2(\mathbb{R})\) 中的所有点都处于平等地位.

变换群在整个几何学中至关重要.一个几何图形的性质必须在适当的变换下保持不变才有意义.\(\mathbb{R}^2\) 中的仿射变换形如 \(T(\mathbf{x}) = A\mathbf{x} + \mathbf{b}\)，其中 \(\mathbf{x} = (x,y) \in \mathbb{R}^2\)，\(A\) 是一个 \(2 \times 2\) 可逆矩阵，\(\mathbf{b}\) 是一个平移向量.如果 \(A\) 是正交矩阵，则该变换 \(T\) 是欧氏变换.众所周知，每个非退化圆锥曲线都可以通过欧氏变换化为标准形式 (a)-(c) 之一.读者可以尝试证明，任何圆锥曲线都可以通过仿射变换化为形式 (a)-(l) 之一.

\(\mathbb{P}^2(\mathbb{R})\) 的射影变换或射影映射是形如 \(T(\mathbf{X}) = M\mathbf{X}\) 的映射，其中 \(M\) 是一个可逆的 \(3 \times 3\) 矩阵.要理解这种变换对仿射部分 \(\mathbb{R}^2 \subset \mathbb{P}^2(\mathbb{R})\) 的作用，可以将其视为一个部分定义的映射 \(\mathbb{R}^2 \to \mathbb{R}^2\)，它是一个分式线性变换：

\(
\begin{pmatrix} x \\ y \end{pmatrix} \mapsto \frac{A\begin{pmatrix} x \\ y \end{pmatrix} + \mathbf{b}}{c_1x + c_2y + d}, \quad \text{其中 } M = \begin{pmatrix} A & \mathbf{b} \\ \mathbf{c}^T & d \end{pmatrix}
\)

当分母 \(c_1x + c_2y + d = 0\) 时，\(T\) 未定义.这或许看起来不够直观，但它确实存在于自然界中：同一平面物体的两张不同照片显然通过射影变换相关联.因此，从事卫星摄影解译等工作的数学家会频繁地计算射影变换.

在本文中，射影变换常以“通过适当选择坐标，我们可以假设……”的形式被隐含地使用.

\section{圆锥曲线的方程}

一个非齐次的二次多项式

\(
q(x,y) = ax^2 + bxy + cy^2 + dx + ey + f
\)

对应于一个齐次的二次多项式

\(
Q(X,Y,Z) = aX^2 + bXY + cY^2 + dXZ + eYZ + fZ^2
\)

这种对应关系可以视为一个操作步骤，也可以看作由 \(q \leftrightarrow Q\) 给出的双射

\(
q(x,y) = Q(x,y,1) \quad (\text{令 } Z=1)
\)

反之，

\(
Q(X,Y,Z) = Z^2 q(X/Z, Y/Z)
\)

射影平面 \(\mathbb{P}^2\) 中的圆锥曲线 \(C\) 是由 \(C: Q(X,Y,Z) = 0\) 定义的曲线，其中 \(Q\) 是一个二次齐次多项式.注意，条件 \(Q(X,Y,Z) = 0\) 在等价类上是良定义的，因为对于任意 \(\lambda \in \mathbb{R} \setminus \{0\}\)，有 \(Q(\lambda\mathbf{X}) = \lambda^2 Q(\mathbf{X})\).作为练习，请验证射影曲线 \(C\) 在仿射平面 \(\mathbb{R}^2\) 中的部分恰好是由 \(q=0\) 给出的仿射圆锥曲线.

\subsection{“无穷远直线”与渐近方向}

\(\mathbb{P}^2\) 中满足 \(Z=0\) 的点对应于比例 \((X:Y:0)\).这些点构成了无穷远直线，它是 \(\mathbb{P}^1(\mathbb{R}) = \mathbb{R} \cup \{\infty\}\) 的一个副本（因为映射 \((X:Y) \mapsto X/Y\) 定义了从 \(\mathbb{P}^1(\mathbb{R})\) 到 \(\mathbb{R} \cup \{\infty\}\) 的双射）.

\(\mathbb{P}^2\) 中的直线由方程 \(L: aX + bY + cZ = 0\) 定义，且

\(
L \text{ 经过点 } (X,Y,0) \iff aX + bY = 0
\)

在仿射坐标中，同一条直线由 \(ax + by + c = 0\) 给出，因此所有具有相同斜率（即相同比例 \(a:b\)）的直线都通过同一个无穷远点.这正是“平行线在无穷远处相交”的精确含义.

例 (a) 双曲线 \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\) 在 \(\mathbb{R}^2\) 中对应于 \(\mathbb{P}^2(\mathbb{R})\) 中的曲线 \(C: \frac{X^2}{a^2} - \frac{Y^2}{b^2} = Z^2\) ；显然它在 \(\left( {Z = 0}\right)\) 中与两点 \(\left( {a, \pm  b,0}\right)  \in  {\mathbb{P}}^{2}\mathbb{R}\) 相交，这两点显然对应于双曲线的渐近线方向.

注意，在 \(\mathbb{P}^2(\mathbb{R})\) 的另一个仿射片（例如 \(X \neq 0\)）中，若取仿射坐标 \(u=Y/X, v=Z/X\)，则该双曲线方程变为 \(\frac{1}{a^2} - \frac{u^2}{b^2} = v^2\)，即 \(\frac{u^2}{b^2} + v^2 = \frac{1}{a^2}\)，这是一个椭圆.

例 (b) 抛物线 \(y = mx^2\) 在 \(\mathbb{R}^2\) 中对应于 \(\mathbb{P}^2(\mathbb{R})\) 中的曲线 \(C: YZ = mX^2\) ；它现在在单点 \((0,1,0)\) 处与 \(\left( {Z = 0}\right)\) 相交.

因此，在射影平面中，“抛物线的两支在无穷远处相遇”；注意这是一条具有直观意义的陈述（也许你觉得这很难以置信？），但这不是仅凭在 \(\mathbb{R}^2\) 内的思考就能得出的结论，甚至可能没有意义.

\section{\(\mathbb{P}^2\) 中圆锥曲线的分类}

设 \(k\) 是一个特征不为 2 的任意域.回顾二次型线性代数中的两个结果：

\begin{proposition}[A]
存在一个自然的双射关系：
\(
\left\{ \begin{array}{c} \text{二次齐次} \\ \text{多项式} \end{array} \right\} = \left\{ \begin{array}{c} \text{二次型} \\ k^3 \to k \end{array} \right\} \overset{\text{bij}}{\longleftrightarrow} \left\{ \begin{array}{c} \text{对称双线性} \\ \text{形式 on } k^3 \end{array} \right\}
\)
由以下公式给出：
\(
aX^2 + 2bXY + cY^2 + 2dXZ + 2eYZ + fZ^2 \longleftrightarrow \begin{pmatrix} a & b & d \\ b & c & e \\ d & e & f \end{pmatrix}
\)
当对应的双线性形式非退化，即其矩阵非奇异时，该二次型称为非退化的.
\end{proposition}

\begin{theorem}[B]
设 \(V\) 是定义在 \(k\) 上的向量空间，\(Q: V \to k\) 是一个二次型.则存在 \(V\) 的一组基，使得 \(Q\) 可以表示为对角形式：
\(
Q = \varepsilon_1 x_1^2 + \varepsilon_2 x_2^2 + \cdots + \varepsilon_n x_n^2, \quad \text{其中 } \varepsilon_i \in k
\)
（这通常通过 Gram-Schmidt 正交化方法证明.）显然，对于 \(\lambda \in k \setminus \{0\}\)，变量替换 \(x_i \mapsto \lambda x_i\) 会将系数 \(\varepsilon_i\) 变为 \(\lambda^{-2}\varepsilon_i\).

\end{theorem}

\begin{corollary}
在适当的坐标系下，\(\mathbb{P}^2(\mathbb{R})\) 中的任意圆锥曲线必定是以下五种类型之一：
\begin{enumerate}[(\(\alpha\))]
    \item 非退化圆锥曲线，方程为 \(X^2 + Y^2 - Z^2 = 0\)；
    \item 空集，方程为 \(X^2 + Y^2 + Z^2 = 0\)；
    \item 两条相交直线，方程为 \(X^2 - Y^2 = 0\)；
    \item 单点 \((0,0,1)\)，方程为 \(X^2 + Y^2 = 0\)；
    \item 一条重直线，方程为 \(X^2 = 0\).
\end{enumerate}
（当然，还有由 \(0=0\) 给出的整个平面 \(\mathbb{P}^2(\mathbb{R})\).）
\end{corollary}
\begin{proof}
在实数域 \(\mathbb{R}\) 上，任何非零数 \(\varepsilon\) 要么是正的（可以化为 1），要么是负的（可以化为 -1）.因此，我们只需考虑定理 B 中 \(\varepsilon_i \in \{0, 1, -1\}\) 的情况.此外，由于我们只关心零点集 \((Q=0)\)，我们可以将 \(Q\) 乘以 -1.这立即导出了上述列表.
\end{proof}

关于此推论有两点值得注意：首先，该列表比 1.3 节中的仿射分类要短得多.例如，1.3 节中的三种非退化情况（椭圆、抛物线、双曲线）在射影变换下都等价于 \(\alpha\) 型.其次，该列表是从一般代数原理推导出来的，过程更为简洁.

\section{圆锥曲线的参数化}

设 \(C\) 是 \(\mathbb{P}^2(\mathbb{R})\) 中一个非退化且非空的圆锥曲线.根据推论 1.6，通过适当的坐标变换，\(C\) 在射影意义下等价于曲线 \(XZ = Y^2\).该曲线可以被参数化为：

\(
\Phi: \mathbb{P}^1(\mathbb{R}) \to C \subset \mathbb{P}^2(\mathbb{R})
\)

\(
(U:V) \mapsto (U^2 : UV : V^2)
\)
\paragraph{注 1} 其逆映射 \(\Psi: C \to \mathbb{P}^1(\mathbb{R})\) 由下式给出：

\(
(X:Y:Z) \mapsto (X:Y) = (Y:Z)
\)

此处，左侧的比值在 \(X \neq 0\) 时有定义，右侧的比值在 \(Z \neq 0\) 时有定义.由于在曲线 \(C\) 上 \(XZ=Y^2\)，当 \(X,Z\) 不全为零时，这两个比值是相等的.用稍后将引入的术语来说，\(\Phi\) 和 \(\Psi\) 是簇之间的同构.

\paragraph{注 2} 在第 1-2 节中，我们默认任何非空、非退化的圆锥曲线在射影意义下都等价于 \(XZ - Y^2 = 0\).在特征不为 2 的域上，这一点在练习 1.5 中得到了证明.（对特征 2 感兴趣的读者应将此作为非退化圆锥曲线的定义.）

\section{二元齐次形式}

设 \(F(U,V)\) 是变量 \(U,V\) 的一个 \(d\) 次非零齐次多项式（通常称为“形式”），其系数属于某个域 \(k\)：

\(
F(U,V) = a_d U^d + a_{d-1} U^{d-1}V + \cdots + a_i U^i V^{d-i} + \cdots + a_0 V^d
\)

\(F\) 对应一个单变量的非齐次多项式：

\(
f(u) = F(u,1) = a_d u^d + a_{d-1} u^{d-1} + \cdots + a_0
\)

显然，对于 \(\alpha \in k\)，我们有：

\(
f(\alpha) = 0 \iff (u - \alpha) \mid f(u) \iff (U - \alpha V) \mid F(U,V) \iff F(\alpha, 1) = 0
\)

因此，\(f\) 的零点对应于 \(F\) 在 \(\mathbb{P}^1\) 上除点 \((1:0)\)（即“无穷远点” \(\alpha = \infty\)）之外的零点.那么，\(F\) 在无穷远点有零点意味着什么呢？

\(
F(1,0) = 0 \iff a_d = 0 \iff \deg f < d
\)

现在，我们定义 \(F\) 在 \(\mathbb{P}^1\) 上零点的重数为：
\begin{enumerate}[(i)]
    \item 若零点为 \((\alpha:1)\)，其重数等于 \(f(u)\) 在 \(\alpha\) 处的零点重数；
    \item 若零点为 \((1:0)\)，其重数等于 \(d - \deg f\).
\end{enumerate}
因此，\(F\) 在点 \((\alpha:1)\) 处的零点重数是能整除 \(F\) 的 \((U - \alpha V)\) 的最高次幂，而在 \((1:0)\) 处的零点重数是能整除 \(F\) 的 \(V\) 的最高次幂.

\begin{proposition}
设 \(F(U,V)\) 是 \(U,V\) 的一个 \(d\) 次非零形式.则 \(F\) 在 \(\mathbb{P}^1\) 上最多有 \(d\) 个零点.此外，若 \(k\) 是代数闭域，则 \(F\) 在 \(\mathbb{P}^1\) 上恰好有 \(d\) 个零点（计入重数）.
\end{proposition}
\begin{proof}
设 \(m_\infty\) 为 \(F\) 在 \((1:0)\) 处零点的重数.根据定义，\(d - m_\infty\) 是非齐次多项式 \(f\) 的次数.命题因此归结为“一个单变量多项式的根的个数（计入重数）等于其次数”这一熟知事实.
\end{proof}

注意，在代数闭域上，\(F\) 可以分解为线性形式 \(\lambda_i = (a_i U + b_i V)\) 的乘积 \(F = \prod \lambda_i^{m_i}\).在这种表示下，点 \((1:0)\) 对应的线性形式是 \(\lambda_\infty = V\)，与其他点处于完全平等的地位.

\section{Bézout 定理的简单情形}

Bézout 定理指出，如果 \(C\) 和 \(D\) 是次数分别为 \(\deg C = m, \deg D = n\) 的平面曲线，那么它们的交点数为 \(mn\)，前提是：(i) 基域是代数闭合的；(ii) 交点按正确的重数计数；(iii) 我们在 \(\mathbb{P}^2\) 中工作，以正确地包含“无穷远处”的交点.本节将讨论其中一条曲线为直线或圆锥曲线的特殊情况.

\begin{theorem}
设 \(L \subset \mathbb{P}_k^2\) 为一条直线（或 \(C \subset \mathbb{P}_k^2\) 为一条非退化圆锥曲线），并设 \(D \subset \mathbb{P}_k^2\) 是由 \(d\) 次齐次多项式 \(G_d(X,Y,Z)=0\) 定义的曲线.假设 \(L \not\subset D\)（或 \(C \not\subset D\)），则：
\(
\#(L \cap D) \le d \quad (\text{或 } \#(C \cap D) \le 2d)
\)
事实上，通过定义一个自然的交点重数，上述不等式对“按重数计数的点数”依然成立；并且如果 \(k\) 是代数闭合的，则等号成立.
\end{theorem}
\begin{proof}
一条直线 \(L \subset \mathbb{P}_k^2\) 可以用参数化形式表示为：
\(
X = a(U,V), \quad Y = b(U,V), \quad Z = c(U,V)
\)
其中 \(a,b,c\) 是关于 \(U,V\) 的线性形式.例如，若直线由 \( \alpha X + \beta Y + \gamma Z = 0\) 定义且 \(\gamma \neq 0\)，则 \(L\) 可以参数化为：
\(
X = U, \quad Y = V, \quad Z = - \frac{\alpha}{\gamma}U - \frac{\beta}{\gamma}V
\)
类似地，如 (1.7) 所述，一条非退化圆锥曲线 \(C\) 可以参数化为：
\(
X = a(U,V), \quad Y = b(U,V), \quad Z = c(U,V)
\)
其中 \(a,b,c\) 是关于 \(U,V\) 的二次齐次多项式.这是因为 \(C\) 是 \(XZ=Y^2\) 的射影变换，而 \(XZ=Y^2\) 的参数化为 \((X,Y,Z) = (U^2, UV, V^2)\).因此 \(C\) 的参数化形式为：
\(
\begin{pmatrix} X \\ Y \\ Z \end{pmatrix} = M \begin{pmatrix} U^2 \\ UV \\ V^2 \end{pmatrix}
\)
其中 \(M\) 是一个非奇异的 \(3 \times 3\) 矩阵.

\begin{center}
\includegraphics[max width=0.5\textwidth]{images/bo_d3lj80c601uc738kffi0_24_454_273_737_428_0.jpg}
\captionof{figure}{(a) 参数化的直线；(b) 参数化的圆锥曲线}
\end{center}
\hspace*{3em} 

此时，\(L\) (或 \(C\)) 与 \(D\) 的交点，对应于使下式成立的比例 \((U:V)\)：

\(
F(U,V) = G_d(a(U,V), b(U,V), c(U,V)) = 0
\)

在直线情况下，\(F(U,V)\) 是 \(U,V\) 的 \(d\) 次齐次多项式；在圆锥曲线情况下，它是 \(2d\) 次齐次多项式.根据命题 1.8，零点的个数分别不超过 \(d\) 和 \(2d\).
\end{proof}

\begin{corollary}\label{cor:1.10}
若 \(P_1, \dots, P_5 \in \mathbb{P}^2(\mathbb{R})\) 是五个不同的点，且无四点共线，则最多存在一条经过这五个点的圆锥曲线.
\end{corollary}
\begin{proof}
反设存在两条不同的圆锥曲线 \(C_1\) 和 \(C_2\) 都经过这五个点 \(P_1, \dots, P_5\).

\(
C_1 \cap C_2 \supset \{P_1, \dots, P_5\}
\)

若 \(C_1\) 非退化，根据定理 1.9，交点数 \(\#(C_1 \cap C_2)\) 最多为 \(2 \times 2 = 4\)，与存在五个交点矛盾.因此，若 \(C_1\) 非退化，则必有 \(C_1 \subset C_2\).由于 \(C_1, C_2\) 都是由二次多项式定义的，这蕴含了 \(C_1=C_2\)，与假设矛盾.

若 \(C_1\) 是退化的，根据推论 1.6，它必然是一对直线 \(L_1 \cup L_2\).由于五个点中无四点共线，一条直线上最多只能包含三个点.例如，\(L_1\) 上有 \(P_1, P_2, P_3\)，\(L_2\) 上有 \(P_4, P_5\).此时，\(C_2\) 与 \(L_1\) 的交点数 \(\#(C_2 \cap L_1)\) 至少为 3.根据定理 1.9，这只有在 \(L_1 \subset C_2\) 时才可能.同理，\(C_2\) 与 \(L_2\) 的交点数至少为 2，若 \(L_2 \not\subset C_2\)，则交点数恰好为 2.
如果 \(C_2\) 也退化为一对直线 \(L_3 \cup L_4\)，那么 \(C_1 \cap C_2 = (L_1 \cup L_2) \cap (L_3 \cup L_4)\).若 \(C_1 \neq C_2\)，则它们最多共享一条公共直线，例如 \(L_1=L_3\).此时交点集为 \(L_1 \cup (L_2 \cap L_4)\)，包含 \(L_1\) 和一个交点.这要求其余四个点都在 \(L_1\) 上，与“无四点共线”的假设矛盾.
因此，在任何情况下，两条不同的圆锥曲线的交点数都不能达到 5.
\end{proof}

\section{所有圆锥曲线构成的空间}

令

\(
S_2 = \{\text{所有 \(\mathbb{R}^3\) 上的二次型}\} = \{\text{所有 \(3 \times 3\) 对称矩阵}\} \cong \mathbb{R}^6
\)

如果 \(Q \in S_2\)，写作 \(Q = aX^2 + 2bXY + \cdots + fZ^2\).对于给定的点 \(P_0 = (X_0, Y_0, Z_0) \in \mathbb{P}^2(\mathbb{R})\)，我们考虑条件 \(P_0 \in C: (Q=0)\).这个条件可以写成：

\(
Q(X_0, Y_0, Z_0) = aX_0^2 + 2bX_0Y_0 + \cdots + fZ_0^2 = 0
\)

对于固定的 \(P_0\)，这是关于系数 \((a,b,\dots,f)\) 的一个线性方程.因此，所有经过 \(P_0\) 的圆锥曲线对应的二次型构成 \(S_2\) 的一个子空间：

\(
S_2(P_0) = \{Q \in S_2 \mid Q(P_0) = 0\} \cong \mathbb{R}^5 \subset S_2 = \mathbb{R}^6
\)

这是一个 5 维的超平面.对于 \(n\) 个点 \(P_1, \dots, P_n \in \mathbb{P}^2(\mathbb{R})\)，类似地定义：

\(
S_2(P_1, \dots, P_n) = \{Q \in S_2 \mid Q(P_i) = 0 \text{ for } i=1, \dots, n\}
\)

这相当于对 \(Q\) 的 6 个系数 \((a,b,\dots,f)\) 施加了 \(n\) 个线性方程.由此可得：

\begin{proposition}
\(\dim S_2(P_1, \dots, P_n) \ge 6 - n\).
\end{proposition}

我们还可以预期“当 \(P_1, \dots, P_n\) 的位置足够一般时，等号成立”.更准确地说：

\begin{corollary}
如果 \(n \le 5\) 且点 \(P_1, \dots, P_n\) 中无四点共线，则
\(
\dim S_2(P_1, \dots, P_n) = 6 - n
\)
\end{corollary}
\begin{proof}
推论 1.10 表明，当 \(n=5\) 时，\(\dim S_2(P_1, \dots, P_5) \le 1\).结合命题 1.11，我们得到 \(\dim S_2(P_1, \dots, P_5) = 1\).
如果 \(n < 5\)，我们可以加入新的点 \(P_{n+1}, \dots, P_5\)，同时保持无四点共线的条件.由于每增加一个点，子空间的维数至多减少 1，我们有：
\(
1 = \dim S_2(P_1, \dots, P_5) \ge \dim S_2(P_1, \dots, P_n) - (5-n)
\)
结合 \(\dim S_2(P_1, \dots, P_n) \ge 6-n\)，可得 \(\dim S_2(P_1, \dots, P_n) = 6-n\).
\end{proof}

注意，如果给定 6 个点 \(P_1, \dots, P_6 \in \mathbb{P}^2(\mathbb{R})\)，它们不一定落在某条圆锥曲线上.

\section{圆锥曲线束中的退化圆锥曲线}

\begin{definition}
一个\textbf{圆锥曲线束} (pencil of conics) 是形如
\(
C_{(\lambda, \mu)}: \lambda Q_1 + \mu Q_2 = 0
\)
的曲线族，其中 \(Q_1, Q_2\) 是两个固定的二次型.族中的每个成员都线性依赖于参数 \((\lambda, \mu)\).我们可以将比值 \((\lambda:\mu)\) 视为 \(\mathbb{P}^1\) 上的一个点.
\end{definition}

通过观察示例，可以预期当 \((\lambda:\mu)\) 取某些特殊值时，圆锥曲线 \(C_{(\lambda, \mu)}\) 会退化.事实上，记二次型 \(Q\) 对应的 \(3 \times 3\) 对称矩阵为 \(M_Q\)，则圆锥曲线退化的条件是其矩阵行列式为零：
\(
C_{(\lambda, \mu)} \text{ 退化} \iff \det(\lambda M_{Q_1} + \mu M_{Q_2}) = 0
\)
将 \(Q_1\) 和 \(Q_2\) 写成对称矩阵形式，该条件可表达为：
\(
F(\lambda, \mu) = \det \left| \lambda \begin{pmatrix} a & b & d \\ b & c & e \\ d & e & f \end{pmatrix} + \mu \begin{pmatrix} a' & b' & d' \\ b' & c' & e' \\ d' & e' & f' \end{pmatrix} \right| = 0
\)

注意 \(F(\lambda, \mu)\) 是关于 \(\lambda, \mu\) 的一个三次齐次多项式.因此，我们可以对 \(F\) 应用命题 1.8，推导出：

\begin{proposition}
设 \(C_{(\lambda, \mu)}\) 是 \(\mathbb{P}_k^2\) 上的一个圆锥曲线束，且至少包含一条非退化圆锥曲线（即 \(F(\lambda, \mu)\) 不恒为零）.则该束中最多有 3 条退化圆锥曲线.如果 \(k = \mathbb{R}\)，则该束中至少有一条退化圆锥曲线.
\end{proposition}
\begin{proof}
一个三次齐次多项式在 \(\mathbb{P}^1\) 上最多有 3 个零点.在实数域 \(\mathbb{R}\) 上，任何奇数次多项式至少有一个实根.
\end{proof}

\section{例题解析}

设 \(P_1, \dots, P_4\) 是 \(\mathbb{P}^2(\mathbb{R})\) 中 4 个点，且无三点共线.则经过这 4 个点的圆锥曲线束 \(C_{(\lambda, \mu)}\) 包含 3 个退化元素，它们分别是三对直线：\(L_{12} \cup L_{34}\)、\(L_{13} \cup L_{24}\) 和 \(L_{14} \cup L_{23}\) ，其中 \(L_{ij}\) 是通过点 \(P_i, P_j\) 的直线:

\begin{center}
\includegraphics[max width=0.2\textwidth]{images/bo_d3lj80c601uc738kffi0_27_770_1529_362_284_0.jpg}
\end{center}
\hspace*{3em} 

接下来，假设我们从由 \(Q_1 = Y^2 + rY + sX + t\) 和 \(Q_2 = Y - X^2\) 生成的圆锥曲线束出发，尝试找出它们的 4 个交点 \(P_1, \dots, P_4\).

\begin{center}
\includegraphics[max width=0.6\textwidth]{images/bo_d3lj80c601uc738kffi0_28_418_286_869_574_0.jpg}
\end{center}
\hspace*{3em} 

这个过程可以按如下步骤完成：
(1) 找到使 \(C_{(\lambda, \mu)}\) 成为退化圆锥曲线的 3 个比值 \((\lambda:\mu)\).根据上一节的讨论，这等价于求解一个三次方程的 3 个根：

\(
F(\lambda, \mu) = \det \left| \lambda \begin{pmatrix} 0 & 0 & s/2 \\ 0 & 1 & r/2 \\ s/2 & r/2 & t \end{pmatrix} + \mu \begin{pmatrix} -1 & 0 & 0 \\ 0 & 0 & 1/2 \\ 0 & 1/2 & 0 \end{pmatrix} \right|
\)
\(
= -\frac{1}{4} (s^2\lambda^3 + (4t - r^2)\lambda^2\mu - 2r\lambda\mu^2 - \mu^3) = 0
\)

(2) 将其中两条退化圆锥曲线分解为直线对（这需要解两个二次方程）.
(3) 4 个交点 \(P_i\) 就是这些直线的交点.

这个过程为伽罗瓦理论中一般四次方程的求解提供了几何解释.设 \(k\) 为一个域，\(f(X) = X^4 + rX^2 + sX + t \in k[X]\) 是一个四次多项式.考虑两条曲线 \(C_1: Y^2 + rY + sX + t = 0\) 和 \(C_2: Y=X^2\).它们的交点为 \(P_i = (a_i, a_i^2)\)，其中 \(a_i\) (\(i=1, \dots, 4\)) 是 \(f(X)=0\) 的 4 个根.

则直线 \(L_{ij} = P_iP_j\) 由下式给出

\(
L_{ij}: Y = (a_i + a_j)X - a_i a_j
\)

而可约圆锥曲线 \(L_{12} + L_{34}\) 由下式给出

\(
(Y - (a_1+a_2)X + a_1a_2)(Y - (a_3+a_4)X + a_3a_4) = 0
\)

展开后，可以发现它属于由 \(Q_1\) 和 \(Q_2\) 生成的圆锥曲线束.具体来说，它是 \(Q_1 - (a_1+a_2)(a_3+a_4)Q_2 = 0\).因此，使圆锥曲线 \(\lambda Q_1 + \mu Q_2\) 分解为直线对的三个 \(\mu/\lambda\) 值是

\(
- (a_1+a_2)(a_3+a_4), \quad - (a_1+a_3)(a_2+a_4), \quad - (a_1+a_4)(a_2+a_3)
\)

以这三个值为根的三次方程称为四次方程的“辅助三次方程”.它通常通过初等对称多项式理论计算，过程相当繁琐.而上述几何方法仅通过计算一个 \(3 \times 3\) 行列式，就优雅地推导出了这个辅助三次方程.
