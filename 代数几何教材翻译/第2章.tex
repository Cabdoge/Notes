\section{曲线 \(\left( {{y}^{2} = x\left( {x - 1}\right) \left( {x - \lambda }\right) }\right)\) 没有有理参数化}

参数化曲线很方便；例如，如果你对丢番图问题感兴趣，可以期望有一个规则给出所有 \(\mathbb{Q}\) -值点，如(1.1)所示.(1.1)的参数化形式为 \(x = f\left( t\right) ,y = g\left( t\right)\) ，其中 \(f\) 和 \(g\) 是有理函数，即两个多项式的商.

定理 设 \(k\) 为特征为 \(\neq  2\) 的域，且设 \(\lambda  \in  k\) 满足 \(\lambda  \neq  0,1\) ；设 \(f,g \in  k\left( t\right)\) 为满足以下条件的有理函数

\[
{f}^{2} = g\left( {g - 1}\right) \left( {g - \lambda }\right) .
\]
 (*)

则 \(f,g \in  k\) .

这等价于说不存在任何由有理函数给出的非平凡映射 \({\mathbb{R}}^{1} \rightarrow  C : \left( {{y}^{2} = }\right.\)  \(x\left( {x - 1}\right) \left( {x - \lambda }\right) )\) .这反映了簇的一个非常强的“刚性”性质.

该定理的证明是在域 \(k\left( t\right)\) 上的算术，利用了 \(k\left( t\right)\) 是唯一分解整环(UFD) \(k\left\lbrack  t\right\rbrack\) 的分式域的事实.证明较长，准备详细学习或暂时跳过(跳转至2.4).练习2.12中有一个通过在 \(\mathbb{Q}\) 上的算术进行不存在性证明的非常相似的例子.

证明 利用 \(k\left\lbrack  t\right\rbrack\) 是唯一分解整环的事实，我写成

\[
f = r/s\;\text{ with }r,s \in  k\left\lbrack  t\right\rbrack  \text{ and coprime, }
\]

\[
g = p/q\;\text{ with }p,q \in  k\left\lbrack  t\right\rbrack  \text{ and coprime. }
\]

去分母后， \(\left( *\right)\) 变为

\[
{r}^{2}{q}^{3} = {s}^{2}p\left( {p - q}\right) \left( {p - {\lambda q}}\right) .
\]

由于 \(r\) 和 \(s\) 互素，右侧的因子 \({s}^{2}\) 必须整除 \({q}^{3}\) ，同理，由于 \(p\) 和 \(q\) 互素，左侧因子 \({q}^{3}\) 必须整除 \({s}^{2}\) .因此，

\[
{s}^{2} \mid  {q}^{3}\text{ and }{q}^{3} \mid  {s}^{2},\;\text{ so that }{s}^{2} = a{q}^{3}\;\text{ with }a \in  k
\]

( \(a\) 是 \(k\left\lbrack  t\right\rbrack\) 的单位，因此属于 \(k\) ).

然后

\[
{aq} = {\left( s/q\right) }^{2}\;\text{ is a square in }k\left\lbrack  t\right\rbrack  \text{ . }
\]

此外，

\[
{r}^{2} = {ap}\left( {p - q}\right) \left( {p - {\lambda q}}\right) ,
\]

因此通过考虑素因数分解，存在非零常数 \(b,c,d \in  k\) 使得

\[
{bp},\;c\left( {p - q}\right) ,\;d\left( {p - {\lambda q}}\right)
\]

都是 \(k\left\lbrack  t\right\rbrack\) 中的平方.如果我能证明 \(p,q\) 是常数，那么根据前述内容， \(r,s\) 也将是常数，从而证明该定理.为了证明 \(p,q\) 是常数，设 \(K\) 为 \(k\) 的代数闭包；则 \(p,q \in  K\left\lbrack  t\right\rbrack\) 满足下一个引理的条件.

引理2.3 设 \(K\) 为代数闭域， \(p,q \in  K\left\lbrack  t\right\rbrack\) 为互素元素，且假设4个不同的线性组合(即4个不同比值 \(\left( {\lambda  : \mu }\right)  \in  {\mathbb{P}}^{1}K\) 对应的 \({\lambda p} + {\mu q}\) )在 \(K\left\lbrack  t\right\rbrack\) 中均为平方；则 \(p,q \in  K\) .

证明(费马的“无限下降法”)引理的假设和结论在用 \(p,q\) 替换时不受影响

\[
{p}^{\prime } = {ap} + {bq},\;{q}^{\prime } = {cp} + {dq},
\]

其中 \(a,b,c,d \in  K\) 和 \({ad} - {bc} \neq  0\) .因此我可以假设给定的4个平方是

\[
p,\;p - q,\;p - {\lambda q},\;q.
\]

则 \(p = {u}^{2},q = {v}^{2}\) ，且 \(u,v \in  K\left\lbrack  t\right\rbrack\) 互素，满足

\[
\max \left( {\deg u,\deg v}\right)  < \max \left( {\deg p,\deg q}\right) .
\]

现在通过反证法，假设 \(\max \left( {\deg p,\deg q}\right)  > 0\) 且在所有满足引理条件的 \(p,q\) 中取最小.则两者

\[
p - q = {u}^{2} - {v}^{2} = \left( {u - v}\right) \left( {u + v}\right)
\]

和

\[
p - {\lambda q} = {u}^{2} - \lambda {v}^{2} = \left( {u - {\mu v}}\right) \left( {u + {\mu v}}\right)
\]

(其中 \(\mu  = \sqrt{\lambda }\) )在 \(K\left\lbrack  t\right\rbrack\) 中是平方，因此由 \(u,v\) 的互素性，我得出 \(u - v\) 和 \(u + v,u - {\mu v},u + {\mu v}\) 均为平方.这与 \(\max \left( {\deg p,\deg q}\right)\) 的最小性矛盾.证毕.

\section{2.4 线性系统}

写成 \(\left( {X,Y,Z}\right) \}\) 中次数为 \(d\) 的 \({S}_{d} = \{\) 次型；(回想一下，型即齐次多项式).任意元素 \(F \in  {S}_{d}\) 可以唯一表示为

\[
F = \sum {a}_{ijk}{X}^{i}{Y}^{j}{Z}^{k}
\]

其中 \({a}_{ijk} \in  k\) ，求和遍及所有满足 \(i + j + k = d\) 的 \(i,j,k \geq  0\) ；这当然意味着 \({S}_{d}\) 是一个以 \(k\) 为基的向量空间

\({Z}^{d}\)

\[
X{Z}^{d - 1}Y{Z}^{d - 1}
\]

\[
{X}^{d - 1}Z{X}^{d - 2}{YZ}\ldots X{Y}^{d - 2}Z
\]

\[
{X}^{d}\;{X}^{d - 1}Y\;{X}^{d - 2}{Y}^{2}\;\ldots \;{Y}^{d}
\]

特别地， \(\dim {S}_{d} = \left( \begin{matrix} d + 2 \\  2 \end{matrix}\right)\) .对于 \({P}_{1},\ldots ,{P}_{n} \in  {\mathbb{P}}^{2}\) ，定义

\[
{S}_{d}\left( {{P}_{1},\ldots ,{P}_{n}}\right)  = \left\{  {F \in  {S}_{d} \mid  F\left( {P}_{i}\right)  = 0\text{ for }i = 1,\ldots ,n}\right\}   \subset  {S}_{d}.
\]

每个条件 \(F\left( {P}_{i}\right)  = 0\) (更准确地说， \(F\left( {{X}_{i},{Y}_{i},{Z}_{i}}\right)  = 0\) ，其中 \(\left. {{P}_{i} = \left( {{X}_{i} : {Y}_{i} : {Z}_{i}}\right) }\right)\) 是对 \(F\) 的一个线性条件，因此 \({S}_{d}\left( {{P}_{1},\ldots ,{P}_{n}}\right)\) 是维数为 \(\geq  \left( \begin{matrix} d + 2 \\  2 \end{matrix}\right)  - n\) 的向量空间.

引理2.5 设 \(k\) 为无限域，且令 \(F \in  {S}_{d}\) .

(i) 设 \(L \subset  {\mathbb{P}}_{k}^{2}\) 为一条直线；若 \(F \equiv  0\) 在 \(L\) 上，则 \(F\) 在 \(k\left\lbrack  {X,Y,Z}\right\rbrack\) 中可被 \(L\) 的方程整除.即， \(F = H \cdot  {F}^{\prime }\) ，其中 \(H\) 是 \(L\) 的方程，且 \({F}^{\prime } \in  {S}_{d - 1}\) .

(ii) 设 \(C \subset  {\mathbb{P}}_{k}^{2}\) 为非空非退化的圆锥曲线；若 \(F \equiv  0\) 在 \(C\) 上，则 \(F\) 在 \(k\left\lbrack  {X,Y,Z}\right\rbrack\) 中可被 \(C\) 的方程整除.即， \(F = Q \cdot  {F}^{\prime }\) ，其中 \(Q\) 是 \(C\) 的方程，且 \({F}^{\prime } \in  {S}_{d - 2}\) .

如果你认为这个命题显而易见，恭喜你的直觉:你刚刚猜到了 Nullstellensatz(零点定理)的一个特例.现在请自己寻找证明(跳转至 2.6).

证明 (i) 通过坐标变换，我可以假设 \(H = X\) .那么对于任意 \(F \in  {S}_{d}\) ，存在唯一的表达式 \(F = X \cdot  {F}_{d - 1}^{\prime } + G\left( {Y,Z}\right)\) :只需将所有含有 \(X\) 的单项式归入第一个加数，剩下的必定是仅含 \(Y,Z\) 的多项式.现在

\[
F \equiv  0\text{ on }L \Leftrightarrow  G \equiv  0\text{ on }L \Leftrightarrow  G\left( {Y,Z}\right)  = 0.
\]

最后一步成立是因为 (1.8):若 \(G\left( {Y,Z}\right)  \neq  0\) ，则它在 \({\mathbb{P}}_{k}^{1}\) 上最多有 \(d\) 个零点，而若 \(k\) 是无限的，则 \({\mathbb{P}}_{k}^{1}\) 也是无限的.

(ii) 通过坐标变换， \(Q = {XZ} - {Y}^{2}\) .现在我来证明对于任意 \(F \in  {S}_{d}\) ，存在唯一的表达式

\[
F = Q \cdot  {F}_{d - 2}^{\prime } + A\left( {X,Z}\right)  + {YB}\left( {X,Z}\right)  :
\]

如果我将 \({XZ} - Q\) 代入 \(F\) 中所有出现的 \({Y}^{2}\) ，剩下的在 \(Y\) 中的次数为 \(\leq  1\) ，因此形式为 \(A\left( {X,Z}\right)  + {YB}\left( {X,Z}\right)\) .现在如同 (1.7)， \(C\) 是由 \(X = {U}^{2},Y = {UV},Z = {V}^{2}\) 给出的参数化圆锥曲线，因此

\[
F \equiv  0\text{ on }C \Leftrightarrow  A\left( {{U}^{2},{V}^{2}}\right)  + {UVB}\left( {{U}^{2},{V}^{2}}\right)  \equiv  0\text{ on }C
\]

\[
\Leftrightarrow  A\left( {{U}^{2},{V}^{2}}\right)  + {UVB}\left( {{U}^{2},{V}^{2}}\right)  = 0 \in  k\left\lbrack  {U,V}\right\rbrack
\]

\[
\Leftrightarrow  A\left( {X,Z}\right)  = B\left( {X,Z}\right)  = 0\text{ . }
\]

这里最后的等式是通过分别考虑形式 \(A\left( {{U}^{2},{V}^{2}}\right)  + {UVB}\left( {{U}^{2},{V}^{2}}\right)\) 中偶次和奇次项得到的.证毕.

练习 2.2 给出了类似的“显式”零点定理的例子.

推论 设 \(L : \left( {H = 0}\right)  \subset  {\mathbb{P}}_{k}^{2}\) 为一条直线(或 \(C : \left( {Q = 0}\right)  \subset  {\mathbb{P}}_{k}^{2}\) 为非退化圆锥曲线)；假设给定点 \({P}_{1},\ldots ,{P}_{n} \in  {\mathbb{P}}_{k}^{2}\) ，并考虑某固定 \(d\) 的 \({S}_{d}\left( {{P}_{1},\ldots ,{P}_{n}}\right)\) .则

(i) 若 \({P}_{1},\ldots ,{P}_{a} \in  L,{P}_{a + 1},\ldots ,{P}_{n} \notin  L\) 和 \(a > d\) ，则

\[
{S}_{d}\left( {{P}_{1},\ldots ,{P}_{n}}\right)  = H \cdot  {S}_{d - 1}\left( {{P}_{a + 1},\ldots ,{P}_{n}}\right) .
\]

(ii) 如果 \({P}_{1},\ldots ,{P}_{a} \in  C,{P}_{a + 1},\ldots ,{P}_{n} \notin  C\) 和 \(a > {2d}\) ，则

\[
{S}_{d}\left( {{P}_{1},\ldots ,{P}_{n}}\right)  = Q \cdot  {S}_{d - 2}\left( {{P}_{a + 1},\ldots ,{P}_{n}}\right) .
\]

证明 (i) 如果 \(F\) 是 \(d\) 次齐次的，且曲线 \(D : \left( {F = 0}\right)\) 在点 \({P}_{1},\ldots ,{P}_{a}\) 处与 \(L\) 相交，且满足 \(a > d\) ，则根据(1.9)，我必须有 \(L \subset  D\) ，因此根据引理， \(F = H \cdot  {F}^{\prime }\) ；现在由于 \({P}_{a + 1},\ldots ,{P}_{n} \notin  L\) ，显然 \({F}^{\prime } \in  {S}_{d - 1}\left( {{P}_{a + 1},\ldots ,{P}_{n}}\right)\) .(ii)完全相同.证毕.

命题 2.6 设 \(k\) 是一个无限域，且有 \({P}_{1},\ldots ,{P}_{8} \in  {\mathbb{P}}_{k}^{2}\) 个不同的点；假设 \({P}_{1},\ldots ,{P}_{8}\) 中没有4点共线，且没有7点位于非退化二次曲线上，则

\[
\dim {S}_{3}\left( {{P}_{1},\ldots ,{P}_{8}}\right)  = 2.
\]

证明 为简便起见，我称一组点为共二次曲线(conconic)，如果它们都位于同一非退化二次曲线上.(2.6) 的证明分为若干情况.

\section{2.8 平面三次曲线上的群运算}

设 \(k \subset  \mathbb{C}\) 是 \(\mathbb{C}\) 的一个子域， \(F \in  k\left\lbrack  {X,Y,Z}\right\rbrack\) 是定义(非空)平面曲线 \(C : \left( {F = 0}\right)  \subset  {\mathbb{P}}_{k}^{2}\) 的三次型.假设 \(F\) 满足以下两个条件:

(a) \(F\) 是不可约的(因此 \(C\) 不包含直线或圆锥曲线)；

(b) 对每个点 \(P \in  C\) ，存在唯一一条直线 \(L \subset  {\mathbb{P}}_{k}^{2}\) ，使得 \(P\) 是 \(F \mid  L\) 的重根.

注意，从几何角度看，条件(b) 表示 \(C\) 应为非奇异点，所指的直线 \(L\) 是切线 \(L = {T}_{P}C\) (参见例2.3).这将成为在 \(\$ 6\) 中对非奇异性和簇的切空间一般定义的动机.

固定任意点 \(O \in  C\) ，进行如下构造:

构造 (i) 对 \(A \in  C\) ，令 \(\bar{A} = {3rd}\) 为 \(C\) 与直线 \({OA}\) 的交点；

(ii) 对 \(A,B \in  C\) ，写出 \(R = {3rd}\) 为 \({AB}\) 与 \(C\) 的交点，并通过 \(A + B = \bar{R}\) 定义 \(A + B\) (见下图).

定理 上述构造在 \(C\) 上定义了一个阿贝尔群运算，以 \(O\) 作为零元(中性元).证明 结合律是关键；我先从简单部分开始证明.

(I) 我必须证明加法和逆元运算是良定义的.如果 \(P,Q \in  C\) 是任意两点，那么要么 \(P \neq  Q\) ，且直线 \(L = {PQ} \subset  {\mathbb{P}}_{k}^{2}\) 唯一确定，要么 \(P = Q\) ，此时根据假设(b)，存在唯一一条直线 \(L \subset  {\mathbb{P}}_{k}^{2}\) 使得 \(P\) 是 \(F \mid  L\) 的重零点；无论哪种情况， \(F \mid  L\) 都是两个变量的三次型，具有两个给定的 \(k\) 值零点.因此它可以分解为三个线性因子的乘积，因此无一例外，第三个剩余交点 \(R\) 是定义良好的，且其坐标属于 \(k\) .注意，允许任意的 \(P = Q,P = R,Q = R\) 或 \(P = Q = R\) ；这些在代数上对应于 \(F \mid  L\) 具有重零点，在几何上对应于切点和拐点.

\section{2.9 一般情况下的结合律}

现在我给出“充分一般”点的结合律证明:假设 \(A,B,C\) 是 \(C\) 上的三个给定点；则 \(\left( {A + B}\right)  + C = \bar{S}\) 的构造使用了4条直线(见上图)

\]

\(\left( {B + C}\right)  + A = \bar{T}\) 的构造使用了4条直线

\[
{M}_{1} : {BCQ},\;{M}_{2} : {QO}\bar{Q},\;{M}_{3} : A\bar{Q}T\text{ and }{M}_{4} : {TO}\bar{T}.

我想证明 \(\bar{S} = \bar{T}\) ，显然为此只需证明 \(S = T\) ；为此，考虑两个三次曲线

\[

然后根据构造，

\[
C \cap  {D}_{1} = \{ A,B,C,O,R,\bar{R},Q,\bar{Q},S\} ,
\]

\[
\text{ and }C \cap  {D}_{2} = \{ A,B,C,O,R,\bar{R},Q,\bar{Q},T\} \text{ . }
\]

现在只要9个点 \(A,B,C,O,R,\bar{R},Q,\bar{Q},S\) 均不相同，两个三次曲线 \(C\) 和 \({D}_{1}\) 满足推论2.7的条件；因此， \({D}_{2}\) 必定经过 \(S\) ，而这唯一可能的情况是 \(S = T\) .

\section{2.10 连续性证明}

我简述一种“连续性”论证方法，利用了 \(k \subset  \mathbb{C}\) 的事实.记 \({C}_{\mathbb{C}} \subset  {\mathbb{P}}_{\mathbb{C}}^{2}\) 为复化曲线 \(C\) ，即满足同一方程 \(F\left( {X,Y,Z}\right)  = 0\) 的复数比值集合 \(\left( {X : Y : Z}\right)\) .若结合律对所有 \(A,B,C \in  {C}_{\mathbb{C}}\) 成立，则显然对 \(C\) 中的所有点也成立.因此，我可以假设 \(k = \mathbb{C}\) .

关心此事的读者不难找到以下两条陈述的证明(见练习2.8):

引理(i) \(A + B\) 是 \(A\) 和 \(B\) 的连续函数；

(ii)对于所有 \(A,B,C \in  C\) ，存在任意接近 \(A,B,C\) 的 \({A}^{\prime },{B}^{\prime },{C}^{\prime } \in  C\) ，使得由它们构造的9个点 \({A}^{\prime },{B}^{\prime },{C}^{\prime },O,R,\bar{R},Q,\bar{Q},S\) 均不相同.

加法法则是由 \(\left( {A,B}\right)  \mapsto  A + B\) 给出的映射 \(\varphi  : C \times  C \rightarrow  C\) .根据(i)， \(\varphi\) 是连续的，因此以下两个映射(抱歉！)也是连续的

\[
f = \varphi  \circ  \left( {\varphi  \times  {\operatorname{id}}_{C}}\right) \;\text{ and }\;g = \varphi  \circ  \left( {{\operatorname{id}}_{C} \times  \varphi }\right)  : C \times  C \times  C \rightarrow  C
\]

由 \(\left( {A,B,C}\right)  \mapsto  \left( {A + B}\right)  + C\) 和 \(A + \left( {B + C}\right)\) 给出.此外，根据(ii)，构造中9个点均不同的三元组(A, B, C)组成的子集 \(U \subset  C \times  C \times  C\) 是稠密的；由上述论证， \(f\) 和 \(g\) 在 \(U\) 上重合，且因其连续性，故在任意处均重合.证毕.

备注 连续性论证如其所述涉及 \(\mathbb{C}\) 的拓扑，因此并非纯代数的.事实上，加法映射 \(\varphi\) 是簇(varieties) \(\varphi  : C \times  C \rightarrow  C\) 的态射，稍后将证明(见(4.14))，其余论证也可以用这种纯代数形式重新表述:对于使9个点互异的 \(C \times  C \times  C\) 的子集是Zariski拓扑下的稠密开集，且两个在稠密开集上重合的态射必在全体上重合.(希望此备注能为课程其余部分提供有用的动机；若感到困惑，暂时可忽略.)
