\section{内容简介}

代数簇（variety）大致可以定义为多项式方程组的解集：

\[
V = \left\{  {P \in  {k}^{n} \mid  {f}_{i}\left( P\right)  = 0}\right\}   \subset  {k}^{n},
\]

其中 \(k\) 是一个域， \({f}_{i} \in  k\left\lbrack  {{X}_{1},\ldots ,{X}_{n}}\right\rbrack\) 是一族多项式.例如，平面曲线 \(C\) : \(\left( {f\left( {x,y}\right)  = 0}\right)  \subset  {\mathbb{R}}^{2}\) 或 \({\mathbb{C}}^{2}\) 就是一个代数簇.

研究代数簇 \(V\) 时，自然会引出以下几个问题：

\textbf{数论问题}\quad 例如，当 \(k = \mathbb{Q}\) 且 \(V \subset  {\mathbb{Q}}^{n}\) 时，我们如何判断 \(V\) 是否为空？若不为空，又该如何找出其上的所有点？一个在历史上颇具意义的具体案例是费马大定理，它探讨了以下方程的解的个数问题：
\[
{x}^{n} + {y}^{n} = 1\text{ ,其中}x,y \in  \mathbb{Q}\text{且}n \geq  3\text{ ? }
\]

这类问题通常被称为丢番图问题（Diophantine problems）.

\textbf{拓扑问题}\quad 如果 \(k\) 是 \(\mathbb{R}\) 或 \(\mathbb{C}\) （这是常见情形），那么 \(V\) 作为拓扑空间具有哪些性质？例如，前述三次曲线的连通分支个数就是一个明显可见的拓扑不变量.

\textbf{奇异性问题}\quad 簇 \(V\) 在其上一点 \(P \in  V\) 附近的拓扑结构是怎样的？如果 \(f : {V}_{1} \rightarrow  {V}_{2}\) 是两个簇之间的正则映射（例如，多项式映射 \({\mathbb{R}}^{2} \rightarrow  \mathbb{R}\) ），那么 \(f\) 在 \(P \in  {V}_{1}\) 附近的拓扑和几何结构又如何？

\section{具体计算与一般理论}

研究簇有两种可能的方法：

具体的 给定一族特定的多项式 \({f}_{i}\) ，我们常常可以通过对 \({f}_{i}\) 的显式计算来理解簇 \(V\) .当维数 \(n\) 和 \({f}_{i}\) 的次数较低时，或者 \({f}_{i}\) 的形式特别简单时，这种方法不失为一种乐趣.但随着问题复杂度的提升，仅凭计算技巧很快就会变得捉襟见肘，难以揭示问题的本质.

一般的 对 \(V\) 性质的研究会迅速引出一些基本概念，如 \(V\) 上的正则函数（regular functions）、非奇异性（nonsingularity）和切平面、以及簇的维数.例如，像上文提到的三次曲线是一维的，这一观念在初等笛卡尔几何中已经很熟悉；从图像中我们也能直观地理解奇异点的含义.

现在，开设一门本科阶段的代数几何课程，其基本困境在于：对“一般”方法的充分讲解需要引入大量定义，这些定义会占据整个课程，从而挤压了传授实质性内容的时间.因此，我们必须做出妥协.我的解决方案是，仅涵盖一般理论的一小部分，并随时参照具体例子加以说明.故而，这份讲义只包含了构成三年制本科数学课程中代数几何必修核心的“标准教材”内容的一小部分.另一方面，我希望每一节都包含一些具有实质内容的习题和例题.

\section{函数环与几何范畴}

代数几何的独特风格源于它只使用多项式函数（以及有理函数）.为了说明这一点，我们考虑定义在开区间 \(U \subset  {\mathbb{R}}^{2}\) 上的几类函数环：

\begin{itemize}
\item \({C}^{0}\left( U\right)  =\) 所有连续函数 \(f : U \rightarrow  \mathbb{R}\) ；
\end{itemize}

\begin{itemize}
\item \({C}^{\infty }\left( U\right)  =\) 所有光滑函数（即任意阶可微）；
\end{itemize}

\begin{itemize}
\item \({C}^{\omega }\left( U\right)  =\) 所有解析函数（即收敛的幂级数）；
\end{itemize}

\begin{itemize}
\item \(\mathbb{R}\left\lbrack  X\right\rbrack   =\) 多项式环，其元素视为定义在 \(U\) 上的多项式函数.
\end{itemize}

这些函数环之间显然存在包含关系：\(\mathbb{R}\left\lbrack  X\right\rbrack   \subset  {C}^{\omega }\left( U\right)  \subset  {C}^{\infty }\left( U\right)  \subset  {C}^{0}\left( U\right)\) .

它们分别对应于几何学中的一些重要范畴：\({C}^{0}\left( U\right)\) 对应拓扑范畴，\({C}^{\infty }\left( U\right)\) 对应微分范畴（可微流形），\({C}^{\omega }\) 对应实解析几何，而 \(\mathbb{R}\left\lbrack  X\right\rbrack\) 则对应代数几何.我想强调，每一个包含符号“\(\subset\)”都代表着一道巨大的鸿沟，这导致了不同范畴中几何学核心特征的差异.虽然在中学和大学一年级的微积分课程中并未强调这一点，但以任何合理的方式衡量，\({C}^{0}\left( U\right)\) 中的可微函数占比都为零（因此，一个随机选取的连续函数几乎必然是处处不可微的，例如布朗运动的轨迹）.\({C}^{\omega }\left( U\right)\) 与 \({C}^{\infty }\left( U\right)\) 之间的差距，可以通过标准函数 \(\exp \left( {-1/{x}^{2}}\right)\) 的行为来体现：该函数在原点无穷可微，但其泰勒级数在原点却不收敛于函数自身.利用这个函数，可以轻松构造一个 \({C}^{\infty }\) “凸起函数” \(f : \mathbb{R} \rightarrow  \mathbb{R}\) ，使得当 \(\left| x\right|  \leq  {0.9}\) 时 \(f\left( x\right)  = 1\) ，而当 \(\left| x\right|  \geq  1\) 时 \(f\left( x\right)  = 0\) .相比之下，定义在 \(U\) 上的解析函数可以延拓为复变量的解析函数（其幂级数在 \(\mathbb{C}\) 的某个区域内收敛），因此（根据复分析的结论）如果一个解析函数在某个实区间上恒为零，那么它必定在整个定义域上恒为零.这是一种“刚性”性质，它将解析几何与微分拓扑区分开来.

\section{多项式几何}

多项式函数是极为稀少的：多项式环 \(\mathbb{R}\left\lbrack  X\right\rbrack\) 只是一个可数维的 \(\mathbb{R}\)-向量空间，而 \({C}^{\omega }\left( U\right)\) 已经是不可数维的.即使我们允许有理函数——即将 \(\mathbb{R}\left\lbrack  X\right\rbrack\) 扩展到其分式域 \(\mathbb{R}\left( X\right)\) ——情况也并无太大改观.(2.2)节将提供一个例子，展示代数范畴所特有的刚性.仅用多项式和有理函数来构建几何理论，这本身就是一项了不起的成就.不出所料，建立这套理论需要克服诸多困难：

通过交换代数奠定基础 拓扑学和微分拓扑学可以依赖于一整套在本科一、二年级分析课程中教授的 \(\varepsilon  - \delta\) 方法.而代数几何若要只使用多项式环，就必须转而研究诸如多项式环 \(k\left\lbrack  {{X}_{1},\ldots ,{X}_{n}}\right\rbrack\) 及其理想之类的代数对象.换言之，我们必须发展交换代数来替代微积分.希尔伯特零点定理（Nullstellensatz，见下文 \(§3\) ）是一个典型的例子：它是一个具有直接几何直观的命题（本质上是说“在多项式环 \(k\left\lbrack  {{X}_{1},\ldots ,{X}_{n}}\right\rbrack\) 中，不同的函数理想定义了不同的簇 \(V \subset  {k}^{n}\) ”），但其证明却需要一段关于交换代数中有限性条件的漫长论述.

有理映射和函数 由于我们选择只使用多项式，另一个难点是必须引入“部分定义的函数”.正如上文所暗示的“刚性”，我们将看到对于某些簇（实际上是所有射影簇），不存在任何非常数的正则函数（参见例5.1、例5.12及(8.10)中的讨论）.有理函数（即形如 \(f = g/h\) 的“函数”，其中 \(g,h\) 是多项式）在分母为零的点处没有定义.尽管这有些不尽人意，但在代数几何学家的传统中，已根深蒂固地将“有理函数”和“有理映射”理解为“仅在部分区域定义的函数（或映射）”.因此，一个有理映射 \(f : {V}_{1} \rightarrow  {V}_{2}\) 实际上根本不是一个严格意义上的映射；这里的断尾箭头“\(\dashrightarrow\)”也逐渐成为惯例.对此持异议者，建议立即放弃本课程，转而选修一门范畴论的阅读课程.

这绝非小题大做.即使是正则映射（即态射，是真正的映射），也必须定义为在所有点 \(P \in  V\) 处都正则的有理映射（即定义良好，可以选择一个在 \(P\) 点不为零的分母）.与此密切相关的是给出簇的恰当内在定义的难题.在本课程（以及我所知的类似课程）中，我们将定义仿射簇 \(V \subset  {\mathbb{A}}^{n}\) 和拟射影簇 \(V \subset  {\mathbb{P}}^{n}\) ，但不会给出不依赖于嵌入空间的“簇”的恰当定义.粗略地说，一个簇应当是将若干个仿射簇沿着同构的开子集“粘合”而成的对象.但在我们目前的语言体系中，同构本身通常是通过有理函数明确定义的，这使得操作变得异常繁琐.描述这种粘合过程的恰当语言是层（sheaves），相关内容在研究生教材中有更好的论述.

\section{“纯代数定义”}

以上是代数几何方法的缺点.话虽如此，当今世界上几乎所有重要的代数簇都是拟射影簇，因此我们可以在不太纠结于定义细节的情况下，尽情享受研究簇的乐趣.

代数几何的主要优势在于其定义是纯代数的，因而适用于任何域，而不仅仅是 \(\mathbb{R}\) 或 \(\mathbb{C}\) .我们可以在特征为 \(p\) 的域上做几何.请不要认为“特征为 \(p\) 没什么大不了的，那只是有限域而已”.首先，群论的相当一部分内容建立在有限域的几何之上，计算机科学中使用的组合学亦是如此.其次，存在许多有趣的非有限的特征 \(p\) 域.此外，在更深的层次上，有限域及其几何性质对研究 \(\mathbb{Q}\) 和 \(\mathbb{C}\) 上的问题也发挥着作用.许多关于 \(\mathbb{Q}\) 上簇的算术问题的深刻结果，都大量运用了在 \(\mathbb{C}\) 或有限域及其代数闭包上的几何方法.

介绍到此结束.更多相关的通识内容，请参见(2.15)节中的非正式讨论以及最后的 \(§8\) .

\section{本课程的先修知识:}

代数: 二次型、交换环及其理想的基本性质、主理想整环和唯一分解环.

伽罗瓦理论: 域、多项式环、有限扩张、代数扩张与超越扩张、可分性.

拓扑与几何: 拓扑空间的定义、射影空间 \({\mathbb{P}}^{n}\) （我会在课程中再次详细讲解）.

\({\mathbb{R}}^{n}\) 中的微积分: 偏导数、隐函数定理（当讲到时我会提醒你所需的内容）.

交换代数: 有其他交换环的学习经验是可取的，但并非必需.

\section{课程相关领域:}

复变函数论: 定义在 \(\mathbb{C}\) 上的代数曲线是一维复流形，其上的正则函数是全纯函数.因此，本课程与复变函数论密切相关，尽管这种关系不一定立即显现.

代数数论: 例如与费马大定理的关系.

突变理论: 突变是奇点的一种，且本质上总是由多项式函数给出，因此对奇点几何的分析是纯粹的代数几何问题.

交换代数: 代数几何为交换代数提供动机，交换代数为代数几何提供技术支持，两者相辅相成.

\section{第0章习题}

0.1 (a) 证明对于固定的值 \(\left( {y,z}\right) ,x\) 是 \({x}^{3} + {xy} + z = 0\) 的重根当且仅当 \(x =  - {3z}/{2y}\) 和 \(4{y}^{3} + {27}{z}^{2} = 0\) ；

(b) 证明该方程有3个不同的实根当且仅当 \(4{y}^{3} + {27}{z}^{2} < 0\) ；

(c) 画出曲面 \(S : \left( {{x}^{3} + {xy} + z = 0}\right)  \subset  {\mathbb{R}}^{3}\) 及其到(y, z)平面的投影；

(d) 翻开任何一本关于突变理论的书籍或文章进行比较.

0.2 设 \(f \in  \mathbb{R}\left\lbrack  {X,Y}\right\rbrack\) 且设 \(C : \left( {f = 0}\right)  \subset  {\mathbb{R}}^{2}\) .若存在 \(\varepsilon  > 0\) 使得 \(C \cap  B\left( {P,\varepsilon }\right)  = \{P\}\) ，则称点 \(P \in  C\) 为孤立点.举例说明 \(C\) 可以有孤立点.证明若 \(P \in  C\) 是孤立点，则函数 \(f : {\mathbb{R}}^{2} \rightarrow  \mathbb{R}\) 在 \(P\) 处必有局部极大值或极小值，并由此推导出 \(\frac{\partial f}{\partial x}\) 和 \(\frac{\partial f}{\partial y}\) 在 \(P\) 处为零.这证明了实代数曲线的孤立点是奇异点.

0.3 三次曲线:

(i) 画出 \(y = 4{x}^{3} + 6{x}^{2}\) 的图形及其与水平线 \(y = t\) （其中 \(t \in  \left\lbrack  {-1,3}\right\rbrack\) 为整数）的交点；

(ii) 对于相同的 \(t\) 值，画出三次曲线 \({y}^{2} = 4{x}^{3} + 6{x}^{2} - t\) .
