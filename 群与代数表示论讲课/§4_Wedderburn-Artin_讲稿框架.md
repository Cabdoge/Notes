## 一、引入 Artin + 上节衔接（约 7 分钟）

### 1.1 Emil Artin 简介

- 1898–1962，生于维也纳，1937 年因纳粹移居美国
- 主要贡献：类域论、Artin L-函数、Artin 环、辫群
- Wedderburn-Artin 定理的历史：Wedderburn (1908) 证明有限维代数情形，Artin (1927) 推广到满足降链条件的环。课本所讲是有限维版本，而定理最终形态属于 Artin 环理论。

### 1.2 上节回顾：Artin 性与 Noether 性

- **Artin 模**：满足降链条件 (DCC)，即任意降链 \(M_1 \supseteq M_2 \supseteq \cdots\) 终归稳定
- **Noether 模**：满足升链条件 (ACC)，即任意升链 \(M_1 \subseteq M_2 \subseteq \cdots\) 终归稳定
- **有限维 F-代数**自然同时是 Artin 也是 Noether 的（维数有限 → 降链和升链必终止）

### 1.3 Jordan-Hölder 定理成立的条件

> **合成列的存在性依赖于两端条件。**

- 一个模具有合成列（有限长的单模滤过）**当且仅当**它同时是 Artin 模和 Noether 模
- 若合成列存在，则 Jordan-Hölder 定理保证：任意两条合成列的长度相同，且合成因子（同构意义下）唯一确定
- 回到有限维 F-代数：因为维数有限，左正则模 \({_A}A\) 自动满足 Artin + Noether → 合成列存在 → Jordan-Hölder 适用

**过渡语：**

> 既然每个有限维代数的左正则模都有合成列，一个自然的问题是：什么情况下这些合成因子都是单模，且左正则模本身就是单子模的直和？这就是今天要研究的半单代数。

## 二、引子——群表示的两个问题（约 3 分钟）

设 G 为有限群，F 为特征不整除 |G| 的代数闭域。

**问题 1**：为什么 G 的不可约表示个数恰好等于 G 的共轭类个数？

**问题 2**：为什么各不可约表示的维数平方和等于群的阶？即 \(\sum n_i^2 = |G|\)

**揭示本质：**

> 两个问题的答案都隐藏在群代数 FG 的结构中。如果我们能证明
> \[ FG \cong M_{n_1}(F) \times M_{n_2}(F) \times \dots \times M_{n_s}(F) \]
> 那么：
>
> - 单因子数 s = 不可约表示数 = \(\dim_F Z(FG)\) = 共轭类数
> - 维数：\(\dim_F FG = |G| = \sum \dim_F M_{n_i}(F) = \sum n_i^2\)

**点明目标**：本节任务就是证明这一结构定理——Wedderburn-Artin 定理。

## 三、定义半单代数（约 3 分钟）

**(课本 4.1)**

- 定义：有限维 F-代数 A，若左正则模 \({_A}A\) 是其单子模（极小左理想）的直和，则称 A 为半单代数
- 等价刻画：A 是其极小左理想的和（由上述 Jordan-Hölder / 合成列保证直和性）
- 例子：可除代数（本身即极小左理想）
- 群代数在 Maschke 条件下是半单代数（此处 4.2 一句话带过）

## 四、Wedderburn-Artin 定理（约 15 分钟，核心）

**(课本 4.5)**

### 四个等价命题

| 命题  | 内容                                                                             |
| ----- | -------------------------------------------------------------------------------- |
| (i)   | A 是半单代数                                                                     |
| (ii)  | 任意左 A-模是半单模                                                              |
| (iii) | \(A \cong M_{n_1}(D_1) \times \dots \times M_{n_t}(D_t)\)，\(D_i\) 为可除 F-代数 |
| (iv)  | A 同构于单代数的直积                                                             |

### 证明路线（突出重点，压缩细节）

| 方向        | 重点程度 | 讲法                                                                                                                              |
| ----------- | -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| (i)→(ii)   | ★★★   | 重点：任意模 = 有限维 → 写作\(Am_1+\dots+Am_n\)，每个 \(Am_i\) 是半单模的商模 → 仍半单（再次用到 Artin+Noether 保证的有限维性） |
| (ii)→(iii) | ★★★   | 重点讲同构链：同型分解 → Schur 引理 → End 函子 → 矩阵代数。4.4 反代数同构一步口述带过                                          |
| (iii)→(iv) | ★☆☆   | 一句话：可除代数上的全矩阵代数是单代数                                                                                            |
| (iv)→(i)   | ★★☆   | 适度展开：4.3（单⇒半单）并入此处证明                                                                                             |

### (ii)→(iii) 同构链详解

将 \({_A}A\) 作同型分解：

\[
A = n_1S_1 \oplus n_2S_2 \oplus \dots \oplus n_tS_t
\]

其中 \(S_1, \dots, S_t\) 为互不同构的单 A-模。令 \(L_i = n_iS_i\)，则：

1. **Schur 引理** → \(\operatorname{Hom}_A(L_i, L_j) = 0\ (i \neq j)\)，\(\operatorname{Hom}_A(L_i, L_i) \cong M_{n_i}(D_i)\)，其中 \(D_i = \operatorname{End}_A(S_i)\) 是可除代数
2. **推论 2.12** → \(\operatorname{End}_A(n_iS_i) \cong M_{n_i}(D_i)\)
3. **引理 2.8 + 2.11** → \(\operatorname{End}_A(L_1 \oplus \dots \oplus L_t) \cong \operatorname{End}_A(L_1) \times \dots \times \operatorname{End}_A(L_t)\)
4. **引理 4.4**（反代数同构，口述带过）→ \((M_{n_i}(D_i))^{\mathrm{op}} \cong M_{n_i}(D_i^{\mathrm{op}})\)
5. 综上：

\[
\begin{aligned}
A &\cong (\operatorname{End}_A(A))^{\mathrm{op}} \\
  &= (\operatorname{End}_A(L_1 \oplus \dots \oplus L_t))^{\mathrm{op}} \\
  &\cong (\operatorname{End}_A(L_1) \times \dots \times \operatorname{End}_A(L_t))^{\mathrm{op}} \\
  &\cong (M_{n_1}(D_1) \times \dots \times M_{n_t}(D_t))^{\mathrm{op}} \\
  &\cong M_{n_1}(D_1^{\mathrm{op}}) \times \dots \times M_{n_t}(D_t^{\mathrm{op}})
\end{aligned}
\]

## 五、推论展开（约 8 分钟）

### 5.1 单代数分类（课本 4.6）

- 单代数 ⟺ 可除代数上的某个全矩阵代数
- 代数闭域上 ⟺ 某个 \(M_n(F)\)

### 5.2 模结构定理（课本 4.7，精简版）

**(i)** 单模归属于唯一的单因子（用单位元的中心分解证明）

**(ii)** \(M_n(D)\) 有唯一的单模 V：

- \(A \cong nV\)
- \(\dim_F V = n[D:F]\)
- \(\operatorname{End}_A(V) \cong D^{\mathrm{op}}\)

> (iii) 精简为：当 \(\operatorname{End}_A(V) \cong F\) 时 D = F 且表示是全矩阵代数本身。

### 5.3 单模个数定理（课本 4.8）

- 互不同构单模数 = 单因子数 = \(\dim_F Z(A)\)（分裂条件下）
- 这正是引子中"不可约表示个数 = 共轭类数"的推广

## 六、回到群代数（约 5 分钟，收束）

### 6.1 不可约表示个数（课本 4.11）

- FG 的单模个数 ≤ 共轭类数；分裂域上取等号
- 证明：单模个数 = 单因子数 ≤ \(\dim_F Z(FG)\) = 共轭类数

### 6.2 维数定理的代数证明（收束到引子）

- 分裂域下：\(FG \cong M_{n_1}(F) \times \dots \times M_{n_s}(F)\)
- 两边取维数：

\[
\dim_F FG = |G| = \sum_{i=1}^{s} \dim_F M_{n_i}(F) = \sum_{i=1}^{s} n_i^2
\]

↑ **收束到引子的问题**

## 七、推广与展望（约 4 分钟，引入下一章）

### 7.1 审视证明中真正用到的条件

回顾 (i)→(ii)→(iii) 的证明，实际上只用到了：

1. **降链条件 (DCC)** — 即 A 是 Artin 代数/环（保证极小左理想存在、合成列存在）
2. **左正则模是半单模** — 即 A 没有非平凡的 Jacobson 根（\(J(A) = 0\)）

> 有限维性只是 Artin 性 + Noether 性的充分条件，而非必要条件。这暗示定理有更广的适用范围。

### 7.2 Wedderburn-Artin 定理的完全形态

> **定理**（Wedderburn-Artin，Artin 1927）：设 R 是环。则下述等价：
>
> 1. R 是半单环（左 Artin 环且任意左 R-模是半单模）
> 2. R 是左 Artin 环且 Jacobson 根 \(J(R) = 0\)
> 3. \(R \cong M_{n_1}(D_1) \times \dots \times M_{n_t}(D_t)\)，其中 \(D_i\) 为可除环

特别地，对于任意左 Artin 环 R，\(R/J(R)\) 总是半单环，因此同构于可除环上矩阵环的直积。

### 7.3 自然引出下一章

> 这里出现了两个新概念：**Artin 环**与 **Jacobson 根**。
>
> 下一章我们将系统研究一般 Artin 环的结构，核心工具就是 Jacobson 根 J(R)。基本图景如下：
>
> - 对任意环 R，定义 Jacobson 根 J(R)（所有单左模的零化子的交 / 所有极大左理想的交）
> - 对左 Artin 环 R，J(R) 是幂零理想，且 R/J(R) 是半单环
> - 由此，Wedderburn-Artin 定理描述了 R/J(R) 的结构，而 J(R) 本身则需要进一步的理论来刻画
>
> 这正是我们在下一章将要展开的内容。
