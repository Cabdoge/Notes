## 文档类与核心宏包
- 文档类：`ctexbook`，选项 `10pt,b5paper,openany,twoside`
- 核心宏包：`rainbow`（定理类环境）、`bookstyle`（章/节/页眉/目录样式）
- 索引：`imakeidx`，选项 `title=关键词索引, columns=2, columnsep=1.5cm, intoc, options=-s pinyin.ist`（**注意：当前各章节 .tex 文件尚未实际使用 `\index`**）
- 数学：`amsmath`, `amssymb`, `bm`, `empheq`, `physics2`（模块 `ab.legacy,op.legacy,qtext.legacy,diagmat`）
- 图形：`tikz`（库 `decorations.pathreplacing,arrows.meta,cd`）, `graphicx`, `float`
- 表格：`makecell`, `longtable`, `multicol`, `multirow`
- 其他：`cleveref`, `enumitem`, `setspace`（`\setstretch{1.3}`）, `\everymath{\displaystyle}`

## 交叉引用
- **引用命令**: `\cref{...}` 用于定理类引用，`\ref{...}` 用于公式/图引用
- **定理类标签语法**: 使用环境第二可选参数，如 `\begin{theorem}[标题][thm:label]`
- **标签命名规范**: `thm:xxx`、`def:xxx`、`eq:xxx`、`lem:xxx`、`cor:xxx`、`prop:xxx`、`fig:xxx`
- **编号引用**: cleveref 自动添加环境类型前缀

## 自定义命令速查
- 黑体/花体简写：`\mb{...}` → `\mathbb{...}`, `\mcal{...}` → `\mathcal{...}`
- 括号与范数（physics2 ab.legacy 定界符语法）：`\ab(...)` 或 `\ab\{...\}` → 自适应括号；`\norm{...}` → `\|...\|`
- 文本运算符：`\st` → `\,\text{s.t.}`, `\aew` → `\,\text{a.e.}`, `\ie` → `\,\text{i.e.}`
- 微分与常数：`\d` → `\mathop{}\!\mathrm{d}`, `\eu` → `\mathrm{e}`, `\iu` → `\mathrm{i}`
- 声明的运算符：`\ran`, `\Spec`, `\Aut`, `\spann`, `\dist`
- 其他运算符使用 `\operatorname{...}` 内联声明
- 格式命令：`\allbf{...}` (加粗), `\colorbf{...}` (环境对应色加粗), `\bluebf{...}` (结构色加粗)
- `\par` (段间距，用于环境内分段)

## 段落与换行
- 环境内多段使用 `\par` 分隔（不空行）
- 环境外正文段落用空行分隔
- 无段落缩进覆盖

## 公式
- 重要公式/定义式用 `equation*` 或 `equation`(如果要编号)
- 多行推导用 `align*`
- `\everymath{\displaystyle}` 已启用，行内公式自动 displaystyle
- 公式间距已全局压缩（`\abovedisplayskip=4pt` 等）

## 禁止的命令
- 不使用裸 `\langle\rangle` 于定理陈述中（用 `\ab` 替代）
- 句号使用英文句点 `.` 而非中文句号 `。`

## 章节结构
- `\chapter{...}` → `\section{...}` → `\subsection{...}` 层级
- 各章节独立 `.tex` 文件，通过 `\input{...}` 引入主文件
- 有 `cover.tex`（封面）
